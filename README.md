# Wearable AI Chatbot

## Goal

Build a compact wearable AI chatbot capable of:

- Voice interaction
- Fingerprint authentication
- Cloud AI integration
- Real-time audio processing
- Battery-powered operation

## Current Hardware

- ESP32 DevKit (WROOM) (initial development)
- ESP32-S3 SuperMini (migration in progress)
- INMP441 I2S MEMS Microphone

## Current Features

- Audio acquisition
- Real-time waveform visualization
- WAV recording
- Python audio pipeline

## Milestone 1

- ESP32 DevKit (WROOM) audio acquisition working
- Python audio pipeline working
- Oscilloscope working
- WAV recorder working
- ESP32-S3 SuperMini verified and ready for migration
